How it works
1

Build the map

Every account, wallet, key and document — where it lives, who can reach it, what to do first. In plain words; your own AI can scaffold it in minutes.

2

Test it together

A dry run with the person who'll actually use it, so you find what's confusing while you still can. A plan you never tested is only a hope.

3

Leave them one file

They double-click it — it opens offline, no app, no account. So the person you love isn't left guessing.
